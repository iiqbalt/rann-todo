# fitur workspace

deskripsi : sistem saat ini hanya membuat todo sederhana, aku ingin membuat fitur baru yg bisa mengakomodir banyak workspace, jadi ada workspace A, B, C, D dan masing2 workspace bisa memiliki todo nya masing2 secara terpisah

- untuk todo yg saat ini sudah ada maka akan memiliki workspace id null, maka akan dianggap workspace default
- jadi selain ada workspace yg bisa dibuat oleh user, data lama nya ada di workspace default
